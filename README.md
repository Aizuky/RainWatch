# 🌧️ RainWatch

Sistema de monitoramento de chuvas e risco de alagamentos desenvolvido com Django.

O projeto tem como objetivo auxiliar no acompanhamento de sensores climáticos, emissão de alertas e gerenciamento de áreas de risco, utilizando integração com métricas e observabilidade através do Dynatrace.

---

# 🚀 Tecnologias Utilizadas

- Python
- Django
- SQLite
- HTML/CSS
- Dynatrace
- Git & GitHub

---

# 📂 Estrutura do Projeto

rainwatch-dynatrace/
├── sensores/
├── alertas/
├── abrigos/
├── rainwatch/
├── manage.py

---

# ⚙️ Funcionalidades

- Cadastro de sensores
- Monitoramento de dados climáticos
- Emissão de alertas
- Gerenciamento de abrigos
- Integração com observabilidade no Dynatrace
